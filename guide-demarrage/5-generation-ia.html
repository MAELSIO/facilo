Brancher une vraie IA de génération

Pourquoi cette étape passe en dernier

Les templates déterministes actuels (voir PLACEHOLDER_AI_CALL dans chaque fichier outil) produisent déjà des messages cohérents, gratuits à afficher, et sans dépendance externe. L'IA améliore la qualité et la variété — ce n'est pas ce qui bloque un lancement.

Où ça se passe dans le code

Chaque fichier assets/js/tools/*.js (sauf le simulateur d'aides) construit le texte avec des fonctions JavaScript repérables par le commentaire PLACEHOLDER_AI_CALL : buildEmail(), buildSms(), buildDevis(), buildReponse()...

Comment procéder quand vous êtes prêt

  1. Créez un petit backend (une fonction serverless suffit : Vercel Functions, Netlify Functions, Cloudflare Workers...) qui reçoit les champs du formulaire en POST et renvoie le texte généré. Ne jamais appeler l'API IA directement depuis le navigateur : la clé API serait exposée.
  2. Dans chaque fichier outil, remplacez le corps de la fonction marquée PLACEHOLDER_AI_CALL par un appel à ce backend, en gardant la même signature (reçoit les données du formulaire, retourne le texte à afficher).
  3. Écrivez un prompt système par outil (ex. « Tu rédiges des relances de factures impayées pour des artisans français, ton professionnel, jamais menaçant avant la mise en demeure... ») et injectez les champs du formulaire comme variables.
