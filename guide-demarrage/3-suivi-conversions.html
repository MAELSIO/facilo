Mettre en place le suivi des conversions

Pourquoi cette étape passe avant l'IA et la base d'aides

Les checklists de lancement SaaS sont unanimes sur ce point : on installe l'analytics avant le lancement, pas après, pour mesurer le tunnel de conversion dès la toute première visite — pas seulement une fois qu'un problème est déjà suspecté.

Ce qui est déjà prêt côté code

window.FacTrack(eventName, props) (dans common.js) appelle automatiquement window.plausible(...) ou window.umami.track(...) dès que l'un des deux scripts est chargé — aucune autre modification n'est nécessaire côté JavaScript.

Trois événements sont déjà posés dans le code : tool_generated (à la génération d'un résultat), lead_captured (à la capture d'un email, avec l'outil d'origine en propriété), et cta_click_offre (clic vers la page offre).

Ce qu'il reste à faire

Ajoutez le script officiel Plausible ou Umami dans le <head> de chaque page (la ligne est déjà présente en commentaire dans index.html, à dupliquer partout) :

<script defer data-domain="facilo.fr" src="https://plausible.io/js/script.js"></script>

Puis configurez ces trois événements comme « Goals » dans votre dashboard Plausible pour suivre le taux de clic vers l'offre payante, outil par outil — c'est exactement ce qui permettra de savoir lequel des 5 outils gratuits convertit le mieux, et donc où concentrer vos efforts ensuite.
